## 🌟 จุดเด่นและสิ่งที่ได้รับการปรับปรุงใหม่ (Modernization & Mobile-First)

### 1. 🎨 ธีมและอัตลักษณ์โรงเรียน (MHC Smart School Aurora Theme)
- ปรับเปลี่ยนโทนสีและดีไซน์ทั้งหมดเข้าสู่ **Aurora Modern Design** (เฉดสีหลัก: Indigo `#4F46E5` ผสาน Accent Violet `#7C3AED` และเอกลักษณ์สีประจำโรงเรียนเลือดหมู-น้ำเงิน)
- ใช้ชุดฟอนต์มาตรฐานสากล: **Plus Jakarta Sans** คู่กับ **Noto Sans Thai** ทำให้อ่านง่าย ชัดเจน สบายตา
- รองรับ **Dark Mode / Light Mode** สลับธีมได้ทันทีและจดจำการตั้งค่าในเครื่อง
- ติดตั้งตราสัญลักษณ์ (โลโก้) โรงเรียนมหาชัยพิทยาคาร ความคมชัดสูง

### 2. 📱 ใช้งานง่ายบนมือถือและการย้อนกลับ (Mobile-First & Page Routing)
- **ระบบแยกหน้าอิสระและการย้อนกลับ (Separate Page Routing & History API):**
  - แยกแต่ละหน้าเป็นอิสระผ่าน URL Hash Routing (`#/home`, `#/check`, `#/workspace`, `#/workspace/classes` ฯลฯ)
  - รองรับการกดปุ่ม **"ย้อนกลับ" (Back)** ของเบราว์เซอร์, ปุ่ม Back กายภาพของมือถือ Android และ Gestures Swipe Back ของ iOS โดยไม่หลุดออกจากเว็บไซต์
  - มีปุ่ม **"← ย้อนกลับหน้าแรก"** เด่นชัดที่ส่วนหัวของทุกหน้าย่อย
  - เมื่อเปิดหน้าต่าง Modal หรือเมนูสไลด์ด้านข้าง (Mobile Drawer) การกด Back จะปิดหน้าต่างนั้นก่อนอย่างเป็นธรรมชาติ ไม่ทำให้ผู้ใช้หลุดออกจากหน้าเดิม
- **แถบเมนูด้านล่าง (Mobile Bottom Navigation Bar):** เหมือนแอปมือถือ Native ใช้งานด้วยนิ้วโป้งมือเดียวได้อย่างคล่องตัว (เลือกชุมนุม / ตรวจผล / แอดมิน)
- **รองรับ Safe Area Insets** ของ iPhone (ไม่ชนรอยบากหรือแถบขีดล่างหน้าจอ)
- **การ์ดข้อมูลตอบสนองทุกขนาดหน้าจอ:** ไม่มีการล้นหน้าจอ (No horizontal overflow) พร้อมอนิเมชันปุ่มสัมผัส (Active push feedback)

### 3. 🎓 ประสบการณ์ลงทะเบียนสำหรับนักเรียน (Student Experience)
- **เลือกลายชื่อตนเองจากระบบได้ทันที (Student Roster Dropdown & Manual Toggle):**
  - เมื่อนักเรียนเลือกระดับชั้นเรียน (เช่น ม.1/1) ระบบจะดึงรายชื่อนักเรียนในห้องนั้นขึ้นมาเป็น Dropdown ให้เลือกชื่อของตนเองได้ทันที ไม่ต้องพิมพ์ชื่อ-สกุลยาวๆ ให้ยุ่งยาก
  - แสดงสถานะในตัวเลือกชัดเจน: หากนักเรียนคนใดลงทะเบียนไปแล้ว จะแสดง `(ลงทะเบียนแล้ว: ชื่อชุมนุม)` พร้อมปิดการเลือก เพื่อป้องกันการลงซ้ำ
  - มีปุ่มสลับ **"⌨️ พิมพ์ชื่อเอง"** เผื่อกรณีที่เป็นนักเรียนย้ายเข้าใหม่หรือยังไม่มีชื่อในระบบ
  - มีตัวเลือก **"➕ ไม่พบชื่อในรายชื่อ (ต้องการพิมพ์เอง)"** อยู่ท้ายรายการ
- **แถบค้นหาแบบ Real-time:** พิมพ์ชื่อชุมนุม หรือชื่อครูผู้ดูแล ผลลัพธ์กรองทันที
- **ปุ่มตัวกรองสถานะ:** ทั้งหมด / เฉพาะที่ยังว่าง / เต็มแล้ว
- **แถบแสดงความจุ (Live Progress Bar):** แสดงจำนวนที่นั่งที่ลงแล้ว พร้อมจำนวนคงเหลือ และเปลี่ยนสีตามความหนาแน่น (เขียว > ส้ม > แดง)
- **ระบบป้องกันการลงซ้ำ:** นักเรียน 1 คน สามารถลงทะเบียนได้เพียง 1 ชุมนุมเท่านั้น
- **พลุเฉลิมฉลอง (Confetti Animation):** แสดงความยินดีเมื่อบันทึกข้อมูลสำเร็จ
- **บัตรประจำตัวการลงทะเบียนชุมนุม (Digital Pass / Ticket):** 
  - สร้างบัตรดิจิทัลสวยงามระบุชื่อ-สกุล, ชั้น, ชุมนุมที่เลือก, ครูผู้ดูแล, รหัสอ้างอิง และเวลาที่ลงทะเบียน
  - ปุ่ม **"บันทึกรูปภาพบัตร"** (Save as PNG) ลงในเครื่องมือถือของนักเรียนทันที
  - ปุ่ม **"พิมพ์บัตร"** (Print) สำหรับนำส่งครูผู้ดูแล
- **เมนูตรวจสอบผลการลงทะเบียนชุมนุม (Check Status Table with Multi-Filter):** 
  - ตารางแสดงรายชื่อนักเรียนที่ลงทะเบียนทั้งหมด
  - ช่องค้นหาชื่อ-นามสกุลนักเรียนแบบพิมพ์แล้วกรองทันที (Live search)
  - ตัวกรองเลือกระดับชั้นเรียน (Dropdown filter)
  - ตัวกรองเลือกกิจกรรมชุมนุม (Dropdown filter)
  - ปุ่มพิมพ์ตาราง A4 มาตรฐานราชการ
  - ปุ่มส่งออกข้อมูลเป็น CSV / Excel
  - ปุ่มคลิกดูบัตรประจำตัวดิจิทัล (Digital Pass) ของนักเรียนแต่ละคนได้ตลอดเวลา

### 4. 👨‍💼 ระบบจัดการสำหรับผู้ดูแลระบบ (Single Admin & Multi-Teacher Management)
- **โครงสร้างระบบเรียบง่ายแต่ทรงพลัง (Admin-Only Role):**
  - รวมศูนย์การบริหารจัดการไว้ที่บทบาท **ผู้ดูแลระบบ (Admin)** เพียงบทบาทเดียว ไม่ต้องสร้างบัญชีล็อกอินแยกสำหรับครูแต่ละท่าน
- **ระบบจัดการรายชื่อนักเรียน & นำเข้า-ส่งออกไฟล์ CSV (Student Roster & CSV Import/Export):**
  - เพิ่ม/แก้ไข/ลบ รายชื่อนักเรียนรายบุคคล (เลขประจำตัว, ชื่อ-นามสกุล, ชั้นเรียน)
  - **📥 โหลดเทมเพลต CSV (Download Template):** ดาวน์โหลดไฟล์แม่แบบ `.csv` ตัวอย่างที่มีโครงสร้างคอลัมน์มาตรฐาน (`เลขประจำตัว,ชื่อ-นามสกุล,ระดับชั้น`) พร้อมเปิดแก้ไขใน Microsoft Excel ได้ทันทีโดยภาษาไทยไม่เพี้ยน
  - **📤 นำเข้าไฟล์ .CSV (CSV File Upload):** ลากและวาง หรือคลิกเลือกไฟล์ `.csv` จากคอมพิวเตอร์เพื่อนำเข้ารายชื่อนักเรียน รองรับการเข้ารหัสภาษาไทยทั้ง **UTF-8 (พร้อม BOM)** และ **Windows-874 (TIS-620)** ป้องกันปัญหาภาษาต่างดาว 100%
  - **📋 คัดลอกและวางข้อความ (Copy-Paste Text):** รองรับการคัดลอกรายชื่อจาก Excel หรือ Word มาวางในกล่องข้อความได้โดยตรง
  - **⭐ ตรวจหาระดับชั้นอัตโนมัติ (Smart Class Mapping):** ระบบตรวจสอบคอลัมน์ระดับชั้นในไฟล์ CSV อัตโนมัติ (เช่น ม.1/1, ม.1/2) ทำให้นำเข้านักเรียนหลายห้องพร้อมกันได้ในไฟล์เดียว
  - **📊 ส่งออกข้อมูลเป็น CSV (Export Roster):** ดาวน์โหลดรายชื่อนักเรียนที่มีอยู่ในระบบเป็นไฟล์ CSV พร้อมสถานะการลงทะเบียนและชุมนุมที่เลือก
  - ตัวกรองตามระดับชั้นเรียน, สถานะการลงทะเบียน (ลงทะเบียนแล้ว / ยังไม่ลงทะเบียน) และช่องค้นหาชื่อ/รหัสแบบ Real-time
- **พิมพ์ชื่อครูผู้ดูแลชุมนุมได้โดยตรงและเพิ่มได้หลายท่านต่อชุมนุม (Multi-Teacher Chip UI):**
  - ในแต่ละชุมนุม สามารถพิมพ์ชื่อครูผู้ดูแลได้โดยตรง
  - รองรับการเพิ่มครูได้มากกว่า 1 ท่านต่อ 1 ชุมนุม
  - มีระบบ Tag/Chip Badge สวยงาม กด Enter หรือปุ่ม "+ เพิ่มครู" หรือวางข้อความคั่นด้วยเครื่องหมายจุลภาค (,) ได้ทันที
  - สามารถกดลบรายชื่อครูแต่ละท่านได้อย่างง่ายดาย
- **ฟังก์ชันการจัดการระบบครบวงจร:**
  - จัดการกิจกรรมชุมนุม (เพิ่ม / แก้ไข / ลบ / จัดการครูผู้ดูแลหลายท่าน)
  - จัดการระดับชั้นเรียน (ม.1 ถึง ม.6)
  - จัดการรายชื่อนักเรียน (เพิ่มเดี่ยว / นำเข้า Excel / กรองสถานะ)
  - จัดการบัญชีผู้ดูแลระบบ (Admin Accounts)
  - ตั้งค่ากำหนดวันและเวลาเปิด-ปิด ระบบรับสมัครออนไลน์
  - สรุปผลและออกรายงานผู้ลงทะเบียน (กรองตามชุมนุม, ถอนสิทธิ์นักเรียน, พิมพ์รายงาน A4 ราชการ, ส่งออก CSV)

### 5. ⚡ ความเสถียรและความปลอดภัยระดับ Enterprise (Apps Script Backend)
- **LockService Concurrency Guard:** ใช้ Script Lock ป้องกันปัญหา Race Condition เมื่อนักเรียนแย่งกันลงทะเบียนพร้อมกันหลายร้อยคน ไม่ให้โควตาเกินและไม่ให้ข้อมูลทับซ้อน
- **CacheService:** ช่วยลดจำนวนครั้งการอ่าน Google Sheets ทำให้โหลดหน้าเว็บได้รวดเร็วทันใจ
- **Auto-Initialization:** หากนำไปติดตั้งบน Google Sheet ใหม่ ระบบจะสร้างชีต `Settings`, `Users`, `Classes`, `Clubs`, `Registrations`, `Students` และสร้างข้อมูลตัวอย่างให้อัตโนมัติ พร้อมรองรับโครงสร้างคอลัมน์ `Teachers` หลายท่าน

## 🚀 ขั้นตอนการติดตั้งและอัปเดตระบบใน Google Apps Script

1. เปิดโปรเจกต์ Google Apps Script ที่เชื่อมต่อกับ Google Sheets ระบบเลือกชุมนุม
2. คัดลอกโค้ดจากไฟล์ **`code.gs`** ในโฟลเดอร์นี้ ไปวางทับในไฟล์ `Code.gs` บน Apps Script
3. คัดลอกโค้ดจากไฟล์ **`index.html`** ในโฟลเดอร์นี้ ไปวางทับในไฟล์ `index.html` บน Apps Script
4. กดบันทึก (Save Project)
5. คลิกเมนู **การทำให้ใช้งานได้ (Deploy)** -> **การจัดการการทำให้ใช้งานได้ (Manage deployments)**
6. กดปุ่มไอคอน **ดินสอ (แก้ไข)** ที่ Deployment ล่าสุด -> เลือก **เวอร์ชันใหม่ (New version)** -> กด **ทำให้ใช้งานได้ (Deploy)**
7. นำ URL ของ Web App ไปแจกจ่ายให้นักเรียนและคุณครูใช้งานได้ทันที
